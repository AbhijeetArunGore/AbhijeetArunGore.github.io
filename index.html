Active Implementation

Clinivara — Privacy-First Clinical Document Intelligence

A zero-knowledge clinical report intelligence backend that extracts complex findings from lab PDFs, executes an upfront PII/PHI de-identification boundary, and generates patient-friendly explanations in English, Hindi, and Marathi without leaking patient identities to external LLMs.

  • Problem: Sending raw medical PDFs to public LLMs leaks patient names, phone numbers, and Aadhaar IDs beside sensitive health biomarkers. Prompting models to "ignore PII" fails under adversarial edge cases.
  • Solution: An upfront local privacy gate using Microsoft Presidio and spaCy NER that redacts personal entities prior to network transmission, validates biomarkers against Pydantic schemas, and synthesizes multilingual guidance.
  • Verified Impact: 100% of identity markers intercepted locally before network egress; physiological range validation prevents out-of-range clinical anomalies from entering patient summaries.

Deep Technical Architecture & Failure Modes

OCR Layout Normalization: PyMuPDF extracts vector text streams directly from digital clinical PDFs, with automatic fallback to Tesseract OCR when processing scanned paper documents, non-standard tabular columns, or embedded physician signature blocks.

Pre-LLM Isolation Boundary: Personal identity tokens are localized via specialized NER models, cryptographically replaced with deterministic surrogate tokens (e.g. [REDACTED_PATIENT_01]), and quarantined. The remote model context window only ever receives scrubbed clinical biomarkers.

Pydantic Range Validation: Extracted metrics (such as HbA1c, eGFR, Creatinine) are checked against physiological plausibility ranges to catch OCR transposition errors before report generation.

Agentic Clinical RAG — Stateful Multi-Agent Retrieval

A stateful multi-agent clinical decision support prototype built with LangGraph. Instead of a naive single-turn LLM prompt, it decomposes retrieval into bounded agents (Researcher, Skeptic, Scribe, Historian), calibrated hybrid fusion search, and strict citation provenance.

  • Problem: Standard LLMs hallucinate medical citations and overlook critical contraindications (e.g., prescribing full-dose metformin to a patient with renal impairment eGFR < 45).
  • Solution: A deterministic LangGraph multi-agent state machine. The Researcher gathers candidate guidelines via hybrid dense/BM25 search, the Skeptic audits for contraindications, the Scribe synthesizes verified citations, and the Historian maintains encounter state.
  • Verified Impact: 61/61 automated passing unit tests in pytest; 100% Citation Existence Precision, 100% In-Scope Hit Rate@5, and 93.75% Abstention Specificity on out-of-scope medical queries.

Deep Technical Architecture & Failure Modes

Weighted Linear Hybrid Fusion: Pure dense bi-encoder embeddings (e.g. all-MiniLM-L6-v2) frequently overlook exact drug dosages and laboratory threshold cutoffs because the semantic context is 99% identical. We combined dense cosine vectors with sparse Rank-BM25 exact keyword matching, boosting in-scope Top-5 retrieval from 68.75% to 100%.

Startup Index Integrity Validation: The FastAPI service performs automated embedding-dimension and collection validation during boot, immediately failing with explicit error logs if the ChromaDB vector collection diverges from the runtime embedding model.

Deployment: Packaged in a multi-stage, non-root Docker container with deterministic offline evaluation harnesses.

End-to-End Containerized Airflow Weather ETL Pipeline

A production-grade, containerized ETL pipeline orchestrated by Apache Airflow 3.x. Extracts real-time weather streams from the Open-Meteo REST API, cleans and validates tabular records with Pandas, and executes idempotent UPSERT persistence into PostgreSQL backed by Docker Compose.

  • Problem: Transient API timeouts and task retries in naive ETL scripts cause partial database writes and duplicate rows during historical DAG backfills.
  • Solution: Stateless Airflow TaskFlow tasks featuring automated exponential-backoff retries and atomic SQL ON CONFLICT DO UPDATE (UPSERT) writes.
  • Verified Impact: Indefinitely re-runnable across historical timeframes with zero duplicate records; containerized Astronomer runtime monitoring.

Inpatient 30-Day Readmission Risk System (Diabetes 130-Hospitals)

A reproducible, leakage-free machine learning investigation and risk prototype on 101,763 hospital encounters across 71,515 patients. Enforces strict patient-level grouped cross-validation, ICD-9 clinical categorizations, and cost-sensitive evaluation trade-offs.

  • Problem: Standard random train/test splits leak repeated hospital admissions for the same patient into evaluation sets, producing deceptive accuracy metrics that collapse in production.
  • Solution: Implemented strict patient-grouped stratified splitting (GroupShuffleSplit) and structured ontology mapping of 900+ raw ICD-9 codes into 18 validated clinical diagnostic categories.
  • Verified Impact: Honest, scientifically reproducible ROC-AUC of 0.6435 (Recall 52.26%, Precision 16.48% under severe class imbalance), backed by 31 passing unit tests in pytest.
